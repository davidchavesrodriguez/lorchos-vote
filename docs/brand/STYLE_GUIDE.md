# Guía de estilo visual

Esta base visual debe transmitir la identidad de GB Lorchos con claridad y sin competir con el contenido de las votaciones.

## Paleta

- Cian: `#00cdff` (`--color-brand-cyan`), para acentos puntuales.
- Naranja: `#f58a20` (`--color-brand-orange`), para acentos puntuales.
- Azul oscuro: `#152536` (`--color-brand-dark-blue`), color principal de texto y contraste.
- Blanco: `#ffffff` (`--color-brand-white`), fondo principal.

El cian y el naranja no deben usarse como único indicador de un estado ni para texto cuando no alcancen un contraste suficiente.

## Tipografía

- **Montserrat** es la tipografía principal: interfaz, navegación, botones, formularios, tablas, etiquetas, datos, mensajes y texto funcional.
- **Cormorant Garamond** se reserva para titulares editoriales y momentos concretos de identidad.

Montserrat debe tener siempre más presencia que Cormorant Garamond.

## Principios

- Claridad antes que decoración y diseño mobile-first.
- Identidad GB Lorchos reconocible, sin estética SaaS genérica.
- Sin degradados decorativos, glassmorphism, glows, blobs, sombras gratuitas ni exceso de tarjetas.
- Estados comprensibles mediante texto, forma o contexto; nunca únicamente por color.
- Accesibilidad desde el inicio: contraste suficiente, foco visible y jerarquía legible.
